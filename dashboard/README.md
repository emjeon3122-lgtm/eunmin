# 실적 대시보드 (1단계: 내 PC용)

ERP에서 받은 계약·매출 엑셀과 입력용 엑셀을 올리면 본부별 대시보드가 자동으로 만들어지는 HTML 파일입니다.
기존 1차 가공 파일의 '데이터요약' 시트와 보고용 파일의 '대시보드' 시트를 대신합니다.

- **설치 없음**: `dist/실적대시보드.html` 을 크롬이나 엣지로 열면 됩니다.
- **데이터가 PC 밖으로 나가지 않음**: 파일은 브라우저 안에서만 읽고, 페이지는 외부 접속이 차단되어 있습니다(CSP).
  창을 닫으면 올린 데이터는 사라집니다. 화면 위쪽 **'이 PC에 저장'**을 켜면 올린 엑셀을 이 PC 브라우저(IndexedDB)에 보관했다가
  다음에 열 때 자동으로 다시 불러옵니다. 같은 이름의 파일을 다시 올리면 이전 것을 대신합니다.
  '저장됨 ✓ (지우기)' 또는 '처음으로'를 누르면 저장한 자료가 지워집니다. 여러 사람이 함께 쓰는 PC에서는 켜지 마세요.

## 매월 하는 일

1. ERP 계약·매출 다운로드 파일을 받는다. 기존 작업 파일(예: `FY2026 실적보고자료(26.08)-data.xlsx`)을 그대로 올려도 됩니다.
2. `입력용.xlsx` 에 이번 달 **인원 · 자금 · 기장추가 · 사유**를 입력한다.
3. 대시보드를 열고 `입력용.xlsx` + 이번 달 파일 + **지난달 파일**을 한 번에 올린다.
   지난 달들 파일도 함께 올리면 월별 추이와 전월 대비가 모두 채워집니다.

## 과거 자료 확정(마감)

1. `입력용.xlsx` 와 확정할 달들의 월별 파일(예: 25.04월 ~ 26.08월 1차 가공 파일)을 한 번에 올린다.
2. `검증` 탭에서 파일마다 기준월이 맞는지 확인하고, '마감(확정) 자료'에서 마지막 월을 골라 **마감자료 파일 만들기**를 누른다.
3. 받은 `실적대시보드_마감자료_YY.MM.json` 을 OneDrive 대시보드 폴더에 둔다.
4. 이후에는 `입력용.xlsx` + 마감자료 + 이번 달 파일만 올린다. 마감자료에 든 달은 🔒 확정으로 표시되고,
   같은 달 파일을 다시 올려도 확정값을 바꾸지 않는다(검증 탭에 안내).
5. 다음 달 마감 때는 마감자료 + 새 달 파일을 올린 뒤 마감자료를 다시 만들어 교체한다.

- 마감자료에는 계산에 필요한 칸(계약번호, 사업부, 계약구분, 계약상태, 회사명, 보고서명, 체결일, 신규여부, 계약·매출 금액, 수기 행, 미수금)만 담긴다.
  실적 데이터이므로 저장소에 올리지 않는다.
- 자료가 여러 회계연도에 걸치면 `FY2025 / FY2026` 버튼으로 연도를 고른다. 사업계획 시트의 `연도` 칸으로 연도별 계획을 넣는다.
- 전년 동월 값은 입력용 `전년실적`에 그 달이 있으면 그 값(공식 값), 없으면 작년 같은 달 자료로 계산한다.

## 조직 변경(본부매핑 이력)과 현재 조직 기준 / 보고 당시 기준

`본부매핑` 시트 칸: `사업부 | 본부 | 적용시작월 | 현재 본부 | 메모`

- 조직이 바뀌면 기존 줄을 지우지 말고 **적용시작월**(예: `26.10월`)을 적은 줄을 추가한다. 그 달부터 새 줄을 쓴다.
  적용시작월이 빈 줄은 '처음부터'. 새 본부(예: 법인재무)·새 사업부도 줄만 추가하면 된다.
- **현재 본부**는 같은 사업부 이름이 시기마다 전혀 다른 팀일 때만 적는다.
  예: 옛 `서울4감사3`(→ 지금 6팀)과 26.04월부터 같은 이름을 쓰는 구 법인감사(4본부)
  ```
  서울4감사3 | 4본부 |         | 6팀 | 옛 4감사3 (26.04월 6팀으로 이동)
  서울4감사3 | 4본부 | 26.04월 |     | 구 법인감사가 이 이름을 씀
  법인 감사  | 법인공통 |      |     |
  법인 감사  | 4본부 | 26.04월 |     | 4본부 편입
  ```
- **보고 당시 기준**: 그 달에 해당하는 줄의 `본부`. 확정(🔒)한 달은 확정 순간의 매핑(+중분류매핑)을 함께 저장해 두고
  그 매핑을 쓰므로, 이후 본부매핑을 바꿔도 바뀌지 않는다. 마감자료·서버 백업에도 들어간다.
- **현재 조직 기준**(기본): 그 줄의 `현재 본부`, 비어 있으면 그 사업부의 가장 최근 줄의 본부. 지금 조직으로 과거까지 다시 나눈다(전년 대비 비교용).
- 원본 금액과 법인 전체 합계는 두 기준이 같다. 화면 위 '조직 기준' 버튼으로 바꾼다(이력이나 확정된 달이 있을 때 표시).
  당시 본부별 계획이 달랐다면 `사업계획`에 `기준`=`보고당시` 줄을 추가한다.
- 옛 양식의 `적용연도` 칸·`본부매핑(보고당시)` 시트는 더 이상 쓰지 않는다(검증 탭에 안내).
- 입력용 `전년실적` 시트는 더 이상 필요 없다(작년 원본에서 계산). 있으면 그 값이 우선하므로, 작년 원본을 모두 올렸다면 지운다.

## 파일을 알아보는 규칙

| 올린 파일 | 알아보는 방법 |
|---|---|
| 입력용 엑셀 | `본부매핑` 시트가 있으면 입력용으로 봅니다 |
| 계약·매출 원본 | 첫 몇 줄 안에 `계약번호, 사업부, 발행예정금액, 조정매출액, 조정후매출액, 등록일자` 헤더가 있는 시트 |
| 미수금 | `계약번호, 사업부, 1년이상` 헤더가 있는 시트 (1년이상 + 2년이상 합계). 없으면 입력용 `미수금` 시트 값을 씁니다 |

- **기준월**은 등록일자 중 가장 늦은 날짜의 달입니다. 틀리면 `검증` 탭에서 바꿀 수 있습니다.
  예외: 마감 후 다음 달 초에 등록된 건(예: 3월 결산 건이 4월에, 6월 건이 7/2에)이 섞인 파일은, 파일 이름에 달이 있고
  (`FY2025.3월 …`, `(26.03)`) 등록일자가 그 바로 다음 달까지만 있으면 파일 이름의 달을 씁니다(검증 탭 기준일 칸에 표시).
  `FY2025.1월`은 2026년 1월로 읽습니다. 파일 이름의 달이 등록일자보다 늦거나 두 달 이상 차이 나면 등록일자를 따릅니다.
- 한 파일에 원본 시트가 여러 개 있으면(예: 보고용 파일의 `데이터원본`, `데이터원본(전월)`) 각각 다른 달로 읽습니다.
- 계약번호 없이 사업부와 금액만 있는 행(손으로 추가한 기장 행 등)은 **기장 수기분**으로 읽습니다. 1차 가공 파일은 '계약및매출(간략)' 시트의 이런 행을 읽습니다.
  입력용 `기장추가` 시트에 그 달을 적으면 파일 값 대신 입력값을 씁니다(ERP 원본만 올리는 달에 사용).

## 계산 방식 (기존 엑셀과 동일)

- 계약 = 발행예정금액 + 조정매출액, 매출 = 조정후매출액 (금액 단위로 나눔, 기본 백만원)
- 본부 = `본부매핑`(사업부 → 본부, 적용시작월별 이력은 위 설명), 중분류 = `중분류매핑`(계약구분, 비어 있으면 계약종류 → 중분류)
- 달성률 = 계약(또는 매출) ÷ 사업계획
- 전년대비 = 당월 − 입력용 `전년실적`의 같은 달 값
- 전월대비 = 당월 − 지난달. 회계연도 첫 달은 계약·매출은 0과 비교하고, 인원·자금·미수금은 전년 마지막 달과 비교합니다.
- 사업계획의 전년 실적 대비 = 사업계획 − 전년실적의 회계연도 마지막 달 계약

## 화면

- **대시보드**: 사업계획, 달성률(계약/매출), 인원, 월별 누적, 자금, 장기채권. 본부·월 버튼으로 바꿔 봅니다.
- **전월 대비 분석**: 계약/매출 기준을 골라 계약번호로 지난달과 비교하고 신규·증가·감소·삭제·분류변경을 자동 분류합니다.
  중분류별·본부별 요약에서 행을 누르면 그 계약만 걸러 봅니다. 사업부·계약구분이 바뀐 계약은 '분류변경'으로 이전 분류에서 빼고 새 분류에 더합니다. 사유는 입력용 `사유` 시트에서 가져옵니다.
  '사유 미입력'만 CSV로 받아 채운 뒤 `사유` 시트에 붙여 넣으면 편합니다.
- **전년 대비 분석**: 본부별 전년 동월 대비 계약·매출과 올해/작년 월별 누적 추이.
  **중분류별 전년대비 표**에는 '주요 증감 요인'이 자동으로 나옵니다: 전체를 볼 때는 증감이 큰 본부 최대 3곳과 각 본부의
  대표 고객(최대 2곳), 한 본부를 볼 때는 증감이 큰 고객 최대 3곳. 가장 큰 항목의 1/5보다 작은 것은 '기타'로 묶습니다
  (고객은 회사명으로 맞춤 — 계약번호는 해마다 바뀜). 따로 적는 전년대비 사유는 없습니다.
  중분류를 누르면 그 중분류의 신규수임(ERP `신규여부`)·기존 구성과 '신규수임 + 기존 = 합계' 증감, 올해/작년 주요 계약 목록이 나옵니다.
  중분류별 전년 값은 작년 같은 달 ERP 파일(예: 25.08월)을 함께 올려야 나옵니다. 작년 원본에 현재 `본부매핑`을 적용하므로
  입력용 `전년실적` 합계와 다르면 차이를 안내합니다. 계약번호는 해마다 새로 매겨지므로 계약끼리 짝을 짓지는 않습니다.
- **데이터 요약**: 기존 '데이터요약' 시트와 같은 표. CSV로 내려받을 수 있습니다.
- **검증**: 불러온 파일과 기준월, 손익계산서 대사용 원 단위 합계, 해약 건, 매핑표에 없는 값, 입력 누락.

## 개발

```
python build.py                 # src/ + vendor/ → dist/실적대시보드.html
node tests/verify.mjs expected.json 입력용.xlsx 작업파일.xlsx ...   # 숫자 대조(Playwright)
node tests/month-from-name.cjs   # 파일 이름 기준월 규칙
```

- `src/xlsx-reader.js`: 외부 라이브러리 없이 xlsx를 읽는 최소 리더(브라우저 내장 DecompressionStream·DOMParser)
- `src/org.js`: 본부매핑 이력 규칙(화면·서버 공용, `build.py`가 `server/lib/org.js`로 복사)
- `src/model.js`: 시트 인식, 집계, 전월 비교
- `src/store.js`: '이 PC에 저장'(IndexedDB) 보관·복원
- `src/app.js`, `src/styles.css`: 화면
- `vendor/`: Chart.js 4.4.4, chartjs-plugin-datalabels 2.2.0 (MIT)
- 실제 실적 데이터(엑셀, CSV, expected.json)는 저장소에 올리지 않습니다(`.gitignore`).
